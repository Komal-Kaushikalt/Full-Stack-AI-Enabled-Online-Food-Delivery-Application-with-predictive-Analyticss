# Full-Stack AI-Enabled Online Food Delivery Application with Predictive Analytics

##  Project Overview
This project is a full-stack web application developed using the MERN stack (MongoDB, Express.js, React.js, Node.js). It is designed to provide an online food ordering system with AI-based predictive analytics to enhance user experience and business decision-making.

The system allows users to browse food items, place orders, and make payments, while the admin can manage food items, orders, and users efficiently.

---

## 🚀 Features

### 👤 User Features
- User Registration & Login (JWT Authentication)
- Browse food items
- Add to cart & place orders
- Multiple payment options (COD, UPI, Razorpay - working on)
- Order history tracking

### 🛠️ Admin Features
- Add, update, delete food items
- Manage orders
- View user details
- Dashboard overview

### 🤖 AI Features
- Predictive analytics for:
  - Popular food items
  - Customer preferences
  - Order trends
